🌐 APIs REST Utilisées

✈️ OpenSky Network API

URL :

https://opensky-network.org/api/states/all

Méthode : GET

Données retournées :

  • icao24 - Identifiant unique
  • callsign - Indicatif d'appel
  • origin_country - Pays d'origine
  • longitude / latitude - Position
  • baro_altitude - Altitude
  • velocity - Vitesse
Documentation
👤 RandomUser API

URL :

https://randomuser.me/api/?results=10

Méthode : GET

Paramètres :

  • results - Nombre de résultats
  • nat - Nationalités (fr,us,gb...)

Données retournées :

  • name (first, last)
  • email
  • picture (medium, large)
  • nat - Nationalité
Documentation
🌍 REST Countries API

URL :

https://restcountries.com/v3.1/name/{country}

Méthode : GET

Données retournées :

  • name (common, official)
  • capital - Capitale
  • population - Population
  • languages - Langues
  • currencies - Monnaies
  • flags (svg, png)
  • timezones - Fuseaux horaires

⚙️ Techniques JavaScript Utilisées

1. Requêtes AJAX avec jQuery

Utilisation de $.ajax() pour les appels asynchrones aux APIs :

$.ajax({
    url: 'https://opensky-network.org/api/states/all',
    method: 'GET',
    dataType: 'json',
    timeout: 30000,
    success: function(response) {
        // Traitement des données
        processFlightData(response.states);
    },
    error: function(xhr, status, error) {
        // Gestion des erreurs
        showError(error);
    }
});

5. Validation de Formulaires

Validation JavaScript côté client :

// Validation email avec regex
function isValidEmail(email) {
    const regex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
    return regex.test(email);
}

// Validation longueur minimale
if (name.length < 3) {
    showFieldError('#name', 'Minimum 3 caractères');
}

// Confirmation mot de passe
if (password !== confirmPassword) {
    showFieldError('#confirm', 'Mots de passe différents');
}

// Force du mot de passe
function calculateStrength(pwd) {
    let score = 0;
    if (pwd.length >= 8) score += 20;
    if (/[A-Z]/.test(pwd)) score += 20;
    if (/[0-9]/.test(pwd)) score += 20;
    return score;
}
6. Stockage Local (localStorage)

Persistance des données entre les pages :

// Sauvegarder le vol sélectionné
localStorage.setItem('selectedFlight', 
    JSON.stringify(flightData)
);

// Récupérer le vol sélectionné
const flight = JSON.parse(
    localStorage.getItem('selectedFlight')
);

// Supprimer les données
localStorage.removeItem('selectedFlight');
